summary:
  en: Level 1 could build and price an offer but never hand it to a customer. This iteration adds company sender data, a shared on-screen preview and PDF export built from one document model, an export-triggered lock that freezes an offer forever, and logo/colour/wording branding on top of the same document. Alongside it, customer and project search, address intelli-fill, an optional project site address, and shortcuts that create a project or offer straight from the customer screen remove friction from the daily workflow. A deterministic E2E test harness and a dependency-vulnerability remediation close out the level as its release gate. All 15 stories in this iteration are Done; nothing Ready or planned is published here.
  de: Level 1 konnte ein Angebot bauen und bepreisen, aber nie an einen Kunden übergeben. Diese Iteration ergänzt Firmen-Absenderdaten, eine gemeinsame Bildschirmvorschau und einen PDF-Export aus einem Dokumentmodell, eine exportausgelöste Sperre, die ein Angebot dauerhaft einfriert, sowie Logo-/Farb-/Textbranding auf demselben Dokument. Daneben nehmen Kunden- und Projektsuche, Adress-Intelli-Fill, eine optionale Projekt-Standortadresse und Abkürzungen, die direkt vom Kundenbildschirm aus ein Projekt oder Angebot anlegen, Reibung aus dem täglichen Arbeitsablauf. Ein deterministischer E2E-Test-Harness und eine Bereinigung verwundbarer Abhängigkeiten schließen das Level als dessen Release-Gate ab. aiContribution:
  en: "Across Level 2 the AI proposed the mechanisms and I bounded them. It proposed one shared document definition, rendered by QuestPDF for both the on-screen preview and the PDF, so the two can never drift apart; page images rather than an inline PDF, so the same layout holds on Windows and Android; and three separate frozen representations at export — position snapshot, page images, PDF bytes — each doing exactly one job instead of one overloaded blob. It proposed the atomic deferred create behind the customer-screen shortcut, so an abandoned draft leaves no orphan project, and it found the gap that made the shortcut unusable at all: a project with no offerable positions could never reach a valid offer draft. Where it was wrong, it was corrected in the open — its root cause for the non-deterministic E2E suite was disproven by measurement, and the story keeps the superseded hypothesis instead of rewriting it away. The calls stayed mine: an Exported offer never re-freezes or relabels when a new version comes off it; the export-confirmation suppression lives on CompanySettings and stays reversible from Settings; the Kleinunternehmer tax fact belongs to the company settings, not to branding; and a time-boxed dependency suppression is acceptable only while the app is not yet productive."
  de: "Über Level 2 hinweg schlug die KI die Mechanismen vor, und ich zog die Grenzen. Sie schlug eine gemeinsame Dokumentdefinition vor, von QuestPDF sowohl für die Bildschirmvorschau als auch für das PDF gerendert, damit beide nie auseinanderlaufen; Seitenbilder statt eines eingebetteten PDFs, damit dasselbe Layout unter Windows und Android hält; und drei getrennte eingefrorene Repräsentationen beim Export — Positions-Snapshot, Seitenbilder, PDF-Bytes —, von denen jede genau eine Aufgabe erfüllt, statt eines überladenen Blobs. Sie schlug das atomare, verzögerte Anlegen hinter der Abkürzung vom Kundenbildschirm vor, damit ein abgebrochener Entwurf kein verwaistes Projekt hinterlässt, und sie fand die Lücke, die diese Abkürzung überhaupt unbrauchbar machte: Ein Projekt ohne angebotsfähige Positionen konnte nie zu einem gültigen Angebotsentwurf gelangen. Wo sie falsch lag, wurde es offen korrigiert — ihre Ursachenanalyse zum nicht-deterministischen E2E-Suite wurde durch Messung widerlegt, und die Story hält die überholte Hypothese fest, statt sie wegzuschreiben. Die Entscheidungen blieben bei mir: Ein exportiertes Angebot friert nie erneut ein und wird nicht umetikettiert, wenn eine neue Version daraus entsteht; die Unterdrückung der Export-Bestätigung liegt auf den Firmeneinstellungen und bleibt dort umkehrbar; die Kleinunternehmer-Angabe gehört zu den Firmeneinstellungen, nicht zum Branding; und eine zeitlich begrenzte Unterdrückung einer Abhängigkeitswarnung ist nur akzeptabel, solange die Anwendung noch nicht produktiv ist."
