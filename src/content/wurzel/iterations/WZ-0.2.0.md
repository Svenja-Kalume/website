summary:
  en: Level 1 could build and price an offer but never hand it to a customer. This iteration adds company sender data, a shared on-screen preview and PDF export built from one document model, an export-triggered lock that freezes an offer forever, and logo/colour/wording branding on top of the same document. Alongside it, customer and project search, address intelli-fill, an optional project site address, and shortcuts that create a project or offer straight from the customer screen remove friction from the daily workflow. A deterministic E2E test harness and a dependency-vulnerability remediation close out the level as its release gate. All 15 stories in this iteration are Done; nothing Ready or planned is published here.
  de: Level 1 konnte ein Angebot bauen und bepreisen, aber nie an einen Kunden übergeben. Diese Iteration ergänzt Firmen-Absenderdaten, eine gemeinsame Bildschirmvorschau und einen PDF-Export aus einem Dokumentmodell, eine exportausgelöste Sperre, die ein Angebot dauerhaft einfriert, sowie Logo-/Farb-/Textbranding auf demselben Dokument. Daneben nehmen Kunden- und Projektsuche, Adress-Intelli-Fill, eine optionale Projekt-Standortadresse und Abkürzungen, die direkt vom Kundenbildschirm aus ein Projekt oder Angebot anlegen, Reibung aus dem täglichen Arbeitsablauf. Ein deterministischer E2E-Test-Harness und eine Bereinigung verwundbarer Abhängigkeiten schließen das Level als dessen Release-Gate ab. Alle 15 Stories dieser Iteration sind Done; nichts Ready oder Geplantes wird hier veröffentlicht.
