body:
  en:
    - "The AI ran two 'consistency passes' and, trying to be helpful, edited 13 already-closed stories so their text matched the current code. That is exactly backwards: a closed story is the record of what was decided and built then, not a description of today. Every one of the 13 was restored byte-for-byte to its pre-pass text."
    - "The fix was not just the revert but a rule that makes the mistake impossible to repeat: a story at status Done keeps the text it had when it closed — it may name a field since deleted or quote an older wording, and that is expected; do not edit it. Current truth lives in the checklist, glossary and reference docs instead. A changed decision is different again — that becomes a new ADR superseding the old one, never an edit to the old one's body. The next day this split was made structural: 27 decisions were extracted into one file each under a frozen, append-only adr/ folder, while the living description moved to reference/ — because the old mixed folder had let the rationale stay right while the description silently drifted."
  de:
    - "Die KI führte zwei „Konsistenzläufe\" durch und bearbeitete — in guter Absicht — 13 bereits abgeschlossene Stories, damit ihr Text zum aktuellen Code passt. Das ist genau verkehrt herum: Eine abgeschlossene Story ist die Aufzeichnung dessen, was damals entschieden und gebaut wurde, keine Beschreibung von heute. Jede der 13 wurde Byte für Byte auf ihren Text vor dem Lauf zurückgesetzt."
    - "Die Korrektur war nicht nur das Zurücksetzen, sondern eine Regel, die den Fehler unwiederholbar macht: Eine Story im Status „Done\" behält den Text, den sie beim Abschluss hatte — sie darf ein längst gelöschtes Feld nennen oder eine ältere Formulierung zitieren, und das ist so gewollt; sie wird nicht bearbeitet. Die aktuelle Wahrheit steht stattdessen in Checkliste, Glossar und Referenzdokumenten. Eine geänderte Entscheidung ist wieder etwas anderes — sie wird zu einer neuen ADR, die die alte ablöst, niemals eine Bearbeitung des alten Textes. Am nächsten Tag wurde diese Trennung strukturell: 27 Entscheidungen wurden in je eine Datei unter einem eingefrorenen, append-only adr/-Ordner ausgelagert, während die lebende Beschreibung nach reference/ zog — denn der alte gemischte Ordner hatte die Begründung richtig bleiben lassen, während die Beschreibung unbemerkt abdriftete."
