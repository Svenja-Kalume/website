body:
  en:
    - The position model had grown two pricing paths — hours priced by Duration, everything else by Quantity × UnitPrice — plus a separate Estimation field left over from an earlier design. During a grooming pass the AI pointed out that Estimation no longer had a job once units arrived; it was only read to compute a price the new rule already computes.
    - We unified everything to PositionPrice = Quantity × UnitPrice for all units, kept Duration as an inert, informational field, removed Estimation from the entity, snapshots and DTOs, and squashed the migration into the initial schema (the dev database is reset anyway). Older done-stories still mention Estimation in their bodies; those stay as immutable history. Fewer fields, one pricing rule, one shared table component — deleting code was the deliverable.
  de:
    - Das Positionsmodell hatte zwei Preispfade entwickelt — Stunden über die Arbeitszeit, alles andere über Menge × Einzelpreis — plus ein separates Schätzungs-Feld aus einem früheren Entwurf. Bei einem Grooming-Durchgang wies die KI darauf hin, dass die Schätzung keine Aufgabe mehr hatte, sobald es Einheiten gab; sie wurde nur gelesen, um einen Preis zu berechnen, den die neue Regel bereits berechnet.
    - Wir vereinheitlichten alles auf Positionspreis = Menge × Einzelpreis für alle Einheiten, behielten die Arbeitszeit als inertes, informatives Feld, entfernten die Schätzung aus Entität, Snapshots und DTOs und quetschten die Migration in das Initial-Schema (die Dev-Datenbank wird ohnehin zurückgesetzt). Ältere fertige Stories erwähnen die Schätzung noch in ihren Texten; die bleiben als unveränderliche Historie. Weniger Felder, eine Preisregel, eine geteilte Tabellen-Komponente — das Löschen von Code war das Ergebnis.
